# Deliverables

Generated presentations are saved here. This is what you send to clients or share with your team.

Every file the agent generates lands here, named after the presentation title:

```
deliverables/
  Q4_Results_Review.pptx
  AI_Strategy_Kickoff.pptx
  Team_Update_Sprint_24.pptx
```

- Files are production-ready and IBM-branded — open directly in PowerPoint
- Source materials used to build each deck are in `sources/`
- To revise a deck: tell the agent which file to update and what to change
- Archive older versions by moving them into a dated subfolder, e.g. `deliverables/archive/2025-07/`
